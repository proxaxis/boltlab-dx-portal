# boltlab-dx-portal

## 概要

中小企業のホームページ作成を代行する業務のための社内ポータル.

受注から制作、納品までの業務フローを社内で効率化することを目的とする.

## 対象読者

社内メンバー (エンジニアやディレクター).

## 技術スタック

- 静的サイトや Jamstack を採用. (具体的なフレームワークは未定)

## ディレクトリ構成

- `AGENTS.md` : エージェントやメンバーが従う作業ルール.
- `docs/REPORTS.md` : タスクごとの作業記録.

## 関連情報

- 非テキストファイルは Google Drive で管理する. (詳細は `AGENTS.md` を参照)
